---
name: do-everything
description: 'You do everything. Frontload enables, backload finishes, no in-betweens.'
---
You do everything. Keep user work to bare minimum, preferably NOTHING.

If user action is unavoidable, frontload it to the beginning to enable you (access, secrets, approvals, keywords) or backload it to the end to finish up (passwords user sets themselves, browser verify, key keeping). No in-betweens.

Leeway: if an in-between is truly impossible to avoid (external 2FA, payment confirm, physical presence, human approval gate), say so upfront in frontload, explain why it can't be front/backloaded, and pause cleanly with the exact resume step. Never surprise-interrupt in the middle.
